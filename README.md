# 把稿子变成分镜表的提示词

做调查类的长视频，最怕画面和稿子对不上、稿子和原件对不上。所以我们每个镜头都要先写清楚：这几秒念哪句，画面拍什么，证据是哪份原件。

这活以前全靠手工。现在我先让 AI 出一版初稿，自己再改。提示词就是 prompt.md，复制了就能用。

## 怎么用

1. 打开 prompt.md，全选复制
2. 拉到最底下有四个括号，把你的东西贴进去：
   - 节拍表：一拍一行，写这一拍讲什么
   - 口播字幕：带时间码的 SRT。没有的话直接贴稿子也行
   - 素材清单：手上有哪些原件、照片、地图。没有就写“无”
   - 风格要求：没有就写“无”
3. 发给 AI

稿子长的话它会一分钟一批的出，回个“继续”就行。

这四样东西长啥样，看 example 文件夹。里面是我们片子里一段 37 秒的真稿子，贴进去的东西（input.md）和 AI 吐出来的东西（output.md）都在。

## 跟别的分镜提示词哪不一样

主要是顺序：先对帐，再想画面。

AI 得先把稿子里每个数字、日期、地点、引语挑出来，跟你给的素材一条条对，对完了才让它设计镜头。

这是吃过亏才加的。我们稿子里有一句“把花坛底下的十几具尸骨全刨了出来”，结果翻 1931 年 11 月 22 号的《时报》，人家标题是“天井中掘屍”。稿子照二手资料写的，跟原件对不上。

有一版提示词我要求加的太多，AI 反而把这处漏了，还照着稿子给我设计了一张“花坛剖面图”。后来把对账挪到第一步，它就把这处标出来了。画面也跟着改了：念到“花坛”的时候，荧光笔划在报纸标题的“天井”两个字上。

## 几句实话

- 它不帮你查证。它只管稿子和你给的素材对不对的上，素材本身准不准，还得自己翻原件
- 提示词里写死了不许编出处，清单里没有的来源只能写“无素材”。前后测了十几次，没见它编过书名页码
- 出来的是初稿。小一点的模型有时候镜头切的特别碎，一两秒一个，得自己合并
- 我只在 Claude 上试过，别家的不知道

随便拿去用，改了也行。
